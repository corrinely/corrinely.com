# Drafts

This folder is the "raw" inbox for corrinely.com. Drop `.md` files here with
nothing but the actual writing — no frontmatter, no formatting, just the
thought as it came out.

`build.py` only reads from `../posts/`, so nothing in here shows up on the
live site until it graduates.

When a draft is ready, ask Claude (in any session with access to this repo)
to turn it into a post. See the `publish-corrinely-draft` skill for exactly
what that conversation looks like.
